## Projects

| # | Project | What I added |
|---|---|---|
| 01 | **Drum kit:** play 9 drum sounds with the keyboard and program a sequence to play back | |
| 02 | **Analog clock** synced with the computer's time | A digital clock whose color changes, which wasn't in the original project |
| 03 | **Weather** for over 200,000 cities using the [OpenWeather](https://openweathermap.org/) API | A swipeable interface with sunrise and sunset times, plus the day's high and low temperatures |
| 04 | **Tic-tac-toe** for two players, with turn indicator, winner and restart button | Colorful interface and a blinking effect on the winner |
| 05 | **Drawing on a canvas** with different colors, tracking the mouse position and drawing continuous lines | |
| 06 | **Quiz** with questions rendered via JavaScript and a final score | Background color feedback on each answer, so you know right away whether you got it right |
| 07 | **Drag and drop** of items between areas, built with the native API | |

## What I learned

The challenge was a great way to explore different parts of JavaScript in a short time: DOM events, audio, `setInterval`, `fetch` with an external API, canvas, and drag and drop. Each project demanded a different way of solving problems.

Thanks to B7Web and Bonieky for the opportunity to take part.

## Running locally

No build step: clone the repository and open `index.html` in your browser. Each project lives in its own `project 0X` folder.

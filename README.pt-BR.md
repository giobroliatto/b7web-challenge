## O que aprendi

O desafio foi um ótimo jeito de explorar partes diferentes do JavaScript em pouco tempo: eventos do DOM, áudio, `setInterval`, `fetch` numa API externa, canvas e drag and drop. Cada projeto pedia uma forma diferente de resolver o problema.

Obrigado à B7Web e ao Bonieky pela oportunidade de participar.

## Rodando localmente

Não tem build: basta clonar o repositório e abrir o `index.html` no navegador. Cada projeto fica na sua pasta `project 0X`.
